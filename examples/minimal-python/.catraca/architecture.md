## Platform and stack

| Dimension | Choice | Origin (answer/assumed) |
|---|---|---|
| Server-side: language/runtime | Python 3.11 | answer (G2) |
| Server-side: framework | none — plain controllers, exercised directly | answer (G2) |
| Client-side (if any) | none | answer (G2) |
| Database | in-memory store (no external DB) | answer (G2) |
| Other dependencies (hash/tokens/etc.) | none in this slice | answer (G4) |
| Development environment (G2b) | local; ephemeral in-memory store recreated per test | answer (G2b) |

> The quality and test tools are proposed and confirmed in feature 000, per this
> platform — recorded in `tasks/000-quality-pipeline.md`. For this stack:
> `mypy --strict`, `ruff` (zero warnings), `pytest` + `pytest-cov` (fail_under
> 100), git hooks via `core.hooksPath`. Bootstrap: the pre-commit probes with
> `pytest --no-cov` (exit 5 = no tests collected, treated as success) before the
> coverage-enforcing pass, so the setup commits clear the hook with zero tests —
> no `--no-verify`. (A plain `pytest` would exit 1, not 5, because
> `--cov-fail-under` in `addopts` turns the empty run into a coverage failure.)

## Layers

<!-- Profile chosen at Gate B: strict (5 layers). -->

| Layer | Responsibility | May import from |
|---|---|---|
| `domain` | Models and use-case contracts (`Protocol`s) | — (nothing) |
| `data` | Use-case implementations + data protocols | `domain` |
| `presentation` | Controllers, boundary validation, boundary errors | `domain` |
| `validation` | Composite validators | `presentation` |
| `infra` | In-memory store, library adapters | `data` (protocols) |
| `main` | Factories, composition | all |

**Import rule (verifiable):** no module in a layer imports from a layer not in
its "may import from" column. Third-party libraries appear only in `infra`. In
this slice the only cross-layer types are the use-case contracts in `domain` and
the data protocols in `data`.

## Boundaries / Adapters

| External dependency | Protocol (layer that defines it) | Adapter (infra) |
|---|---|---|
| Poll persistence | `AddPollRepository` (`data`) | `PollMemoryRepository` (`infra`) |
| Error log destination | logging protocol (`data`) | structured stdout (default; deferred — not exercised in this slice) |

## Per-layer test conventions

| Layer | Test type | Reference skill |
|---|---|---|
| `domain`/`data`/`presentation` | Unit with test doubles and a `make_sut()` factory | `testing/test-doubles`, `testing/test-setup-factories` |
| `validation` | Unit (composite returns the first error) | `foundational/input-validation` |
| `infra` | Integration with the in-memory store | `testing/integration-tests` |
| `main` | Factory-built controller + real in-memory store | `testing/integration-tests` |
