# Exemplo Mínimo — Instalação de Demonstração

Resultado de rodar o instalador numa pasta vazia:

```bash
python3 install.py examples/minimal
```

Mostra exatamente o que um projeto alvo recebe: `.catraca/` com templates
vazios (product, architecture, method, questions, roadmap, ratchet), os 5
comandos, o template da feature 000 (esteira de qualidade), a biblioteca de
13 skills e os atalhos em `.claude/commands/catraca/`.

Nenhum artefato foi preenchido — é o estado "recém-instalado", antes do
`/catraca.init`.
